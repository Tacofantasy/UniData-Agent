# 工具权限控制：当前阶段不实现，保留扩展缺口

当前所有工具为 Mock/公开数据，不存在真实权限风险。工具调用频率受 ReAct 循环上限（默认 5 轮）天然约束。

## 扩展方向（未来）
- 按 `McpToolExecutor` 接口增加 `getRequiredRole()` 方法实现角色级鉴权
- 按部门/组织维度限制工具访问（如财务部数据不可被其他部门查询）
- 工具参数范围限制（如 sales_query 只能查最近 N 个月数据）

理由：权限控制应在接入真实敏感业务工具时再做，当前阶段过早优化增加无谓复杂度。后续实现成本低（接口加方法 + 执行前校验），非难以逆转决策。
